# SkillOpt 训练报告 #006 — 错误分析与规则优化路线

> 日期：2026-07-26 | 分支：`main` | 基于 #005 推理消融的逐题数据

---

## 一、错误分布

基于 TF-IDF Top-5, seed=0, 1400 条 test set：

| 类别 | 数量 | 占比 |
|------|:--:|:--:|
| TF-IDF 正确 | 1031 | 73.6% |
| TF-IDF 错误 | 369 | 26.4% |
| └ 答案在 context 中，仍错 | **313** | — |
| └ 答案不在 context 中 | 56 | — |

### 跨方法对比

| 对比 | 数量 | 解释 |
|------|:--:|------|
| TF-IDF 错、Random 对 | 27 | |
| Random 错、TF-IDF 对 | 34 | |
| 三方法全错 | 328 | 主要是 qwen-flash 能力上限 |

27/34 的互换量级与 qwen-flash 输出噪声 (std≈0.003 = ~4.2 题) 一致，说明**方法间差异主要是模型随机性，并非检索质量问题**。

---

## 二、检测极限

qwen-flash 在 1400 条 test set 上的输出标准差约为 0.003（约 4 题）。

当前瓶颈不是排序公式不够复杂，而是：

```
单规则真实信号 << 评估噪声 (std≈0.003)
```

继续调整 α, β 或引入 LSTM 门控，大概率只会在验证集噪声上过拟合。

---

## 三、为什么历史贡献重排序失败

| 尝试 | Δ vs TF-IDF | 失败原因 |
|------|:--:|------|
| Precision U(r) | — | 高频规则 U≈整体准确率=0.73，无区分度 |
| IDF 频率惩罚 | -0.0043 | 错误惩罚了 R20-R24 等高频但必要的通用规则 |
| Leave-one-out | 0 条正贡献 | 单规则效应 < qwen-flash 噪声 |

三种方法指向同一个问题：单规则真实信号低于当前评估噪声水平。

## 四、规则优化方向

### 4.1 不再改变的基线

```
6 Core + 18 Dynamic
TF-IDF Top-5
token_budget = 2000
冻结，后续只改规则文本。
```

### 4.2 最有价值的优化流程

1. **分析 TF-IDF 错、Random 对的 27 条样本** → 看是否检索了错误的规则
2. **分析 Random 错、TF-IDF 对的 34 条样本** → 看 TF-IDF 检索了什么规则让模型答对了
3. **高频召回规则优先改** → 先统计 18 条规则被 Top-5 选中的频率，优先改高频+高错误率规则

### 4.3 规则文本模板

每条规则建议包含四个部分：

```
触发条件：什么问题需要使用该规则
执行动作：具体应该怎么做
排除条件：什么情况下不要使用
输出约束：答案应保留或删除什么
```

### 4.4 单规则修改验证

- 一次只改一条规则
- 比较 Δ_overall 和 Δ_cluster（该规则对应的错误簇）
- 整体分数未提高但目标簇改善 → 继续收紧排除条件
- 多 seed 验证，不要相信单次运行结果

---

## 五、核心决策

> **冻结检索框架，停止继续增加 LSTM、遗忘门及历史贡献权重，进入规则文本定向优化阶段。**

真正的核心研究问题已经从"如何选择规则"变成了：

> **如何将原子规则写得更具条件性、排他性和可执行性，使正确规则被召回后能够稳定指导 Target 模型。**

---

## 六、实验控制

规则优化阶段补充三项控制：

1. **修改规则只用 200 条开发验证集**（`valid_seen`），1400 条测试集暂不反复参与调整，避免测试集泄漏。
2. **优先分析稳定错误样本**：多个 seed 下均回答错误的样本；seed 间结果不一致的样本单独标记为模型波动，不据此修改规则。
3. **"局部簇初筛 → 完整验证复核"**：先在相关错误簇上检查改善，再在完整验证集上确认无副作用。

### 每次规则迭代记录格式

```text
规则编号与原始文本
修改后的规则文本
修改依据 & 目标错误簇
目标簇修改前后准确率
完整验证集修改前后准确率
新增错误与修复错误数量
3-seed 结果 & 标准差
最终：接受 / 回滚
```

### 接受标准

不只看总体准确率：

```
Δ_cluster > 0
```

同时满足：

```
Δ_overall ≥ 0
```

若总体变化处于模型噪声范围内，但稳定修复了多个目标样本且没有产生明确新错误 → 暂时保留为候选规则，等待与后续同类修改合并验证。

## 七、下一阶段目标

```
冻结 TF-IDF Top-5
    ↓
稳定错误聚类（多 seed 一致错误的样本）
    ↓
规则触发与排除条件优化（一次一条）
    ↓
局部配对验证（目标簇改善）
    ↓
完整验证集复核（无副作用）
    ↓
累计 0.002-0.005 提升
```

## 八、结论

**第二阶段（检索框架探索）已收束。**

- 确定了最终框架：`6C+18D + TF-IDF Top-5 + Gated Slow Update = 0.7386±0.0037`
- 验证了原子化是 RAG 生效的决定性前提
- 确认了当前检索方法已接近检测极限，继续堆叠检索权重无意义

**第三阶段（规则文本优化）即将开始。**

LSTM、遗忘门和更复杂的历史效用重排序已永久移至路线图远端。当前瓶颈是规则文本的条件性、排他性和可执行性。
