# LiveMath Meta-Reasoning Skill

CRITICAL: LiveMath questions have a special format. Option A is often a META-STATEMENT: "One of the remaining options is correct, but a stronger result can be proven." Do not evaluate A as a direct math claim — determine which of B/C/D/E is actually correct, then answer A if exactly one is correct.

Before comparing the math content of the choices, first identify the type of decision:
1. Is the question asking whether a specific proposition is mathematically true?
2. Is it asking about the relationship between theorems (stronger/weaker/equivalent)?
3. Is a meta-level option more directly answering the question?

Select the correct answer. Output ONLY the letter (A/B/C/D/E).
